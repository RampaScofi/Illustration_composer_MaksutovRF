## План экспорта (этап 2)

1. `GET /v1/files/{key}/images?format=svg&ids=0:1&depth=3` — получить
   SVG-картинку всей страницы библиотеки (для визуальной проверки).
2. Парсинг SVG: извлечение `<g>`-групп как компонентов, определение
   `viewBox` и размеров по `absoluteBoundingBox`.
3. Формирование `manifest.json` с полями: `id`, `name`, `size`,
   `role`, `sourceIllustrationId`, `svgPath`, `viewBox`, `intrinsicSize`,
   `tags`.
4. Извлечение цветовых схем из секций «Цвета фона» / «Цвета объектов».
5. Сохранение в `public/assets/illustrations/` и `public/assets/palettes/`.
6. Валидация через `validateLibraryManifest` + `validateColorScheme`.

Экспорт-скрипт выполняется один раз при получении нового исходника,
не является частью runtime-приложения.
