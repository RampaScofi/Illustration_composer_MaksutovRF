# Illustration_composer (VectorMuse)

Веб-сервис для сборки векторных иллюстраций из готовых SVG-компонентов.
Композиция собирается только из элементов исходной библиотеки: сервис
не генерирует и не перерисовывает объекты, итоговый экспорт остаётся
редактируемым SVG без растрирования.

Рабочее название интерфейса — **VectorMuse**.

## О проекте

VectorMuse — веб-редактор векторных иллюстраций. Пользователь описывает
идею на русском языке, сервис подбирает объекты из библиотеки и собирает
из них композицию на холсте. Итог — редактируемый SVG без растрирования.

Что умеет:

- Библиотека из 46 SVG-компонентов (иллюстрации в размерах L/S), 3 цветовые
  схемы и 3 декоративные подложки холста.
- Подбор по описанию: нормализация текста, словарь ассоциаций, ранжирование
  по названию, синонимам и тегам. Локальный подбор работает без внешних API.
- Автокомпоновка: объекты размещаются не по шаблону, а со случайными
  позициями (от зерна, если задано). Бывают крупные главные объекты, смещённые
  от центра, перекрытия, обрезка краем холста, фоновые копии меньшего размера.
  Пропорции объектов и их элементы не меняются; копия объекта — отдельный
  экземпляр, который можно перекрасить или переместить.
- ИИ-компоновка (опционально): модель выбирает объекты из каталога по смыслу
  описания и предлагает до 5 вариантов. Координаты, размеры и цвета задаёт
  приложение. Сама модель не рисует и не меняет объекты.
- Вкладки проектов: несколько композиций в одной сессии, создание,
  переименование, переключение и закрытие. Состояние каждого проекта хранится
  отдельно; при закрытии непустого проекта запрашивается подтверждение.
- Форматы холста: 16:9, 4:3, 1:1, 4:5, 9:16, 3:1. Масштаб contain —
  объекты не деформируются при смене формата.
- Перекраска по выбранной схеме и экспорт самостоятельного SVG с фоном холста.
- Ручное редактирование: выбор, перемещение, поворот, дублирование,
  удаление и порядок слоёв.

Ограничения: локальный подбор — словарный, не языковая модель. Он понимает
термины из названий, синонимов, тегов и словаря ассоциаций и не исправляет
опечатки. Белые контуры в SVG не перекрашиваются.

## ИИ-компоновка

Без подключения нейросети приложение работает полностью локально. Подключение
нужно только для ИИ-вариантов по описанию.

Поддерживаются варианты подключения: OpenAI, Anthropic, Groq и «Свой endpoint
(OpenAI-совместимый)». Groq выбирается из списка провайдеров; адрес endpoint
задан приложением и не меняется.

### Бесплатный доступ через Groq

Groq предоставляет бесплатный тариф с лимитами запросов; условия могут
меняться, проверяйте их в кабинете.

1. Зарегистрируйтесь на https://console.groq.com и создайте ключ в разделе
   API Keys (https://console.groq.com/keys).
2. В панели «Нейросеть» выберите провайдера «Groq (бесплатный тариф)».
3. Адрес endpoint: `https://api.groq.com/openai/v1`
   (приложение добавит `/chat/completions` само).
4. Модель: введите имя модели точно как в кабинете Groq. Список моделей
   доступен по адресу `https://api.groq.com/openai/v1/models` (нужен заголовок
   `Authorization: Bearer <ключ>`). Имена моделей меняются, а доступность
   зависит от аккаунта. Например, на момент проверки работала `openai/gpt-oss-20b`,
   а `llama-3.3-70b-versatile` возвращала 404.
5. Вставьте ключ и включите переключатель ИИ-компоновки.

Если модель не вернула корректный ответ, приложение показывает уведомление
и использует локальный подбор. Модели с режимом рассуждений могут чаще
выдавать ответ, который не проходит проверку формата; в таком случае
попробуйте другую модель из списка.

### Безопасность ключа ИИ

- Ключ хранится в `localStorage` браузера в открытом виде. Любой скрипт,
  выполнившийся на этом сайте (например, через XSS), и любой, кто имеет
  доступ к этому браузеру, может его прочитать. Используйте ключ с
  ограниченными правами и отзывайте его при подозрении на утечку.
- Ключ отправляется только на собственный маршрут `POST /api/ai/compose`,
  который пересылает запрос провайдеру. Ключ не логируется и не возвращается
  в ответах и текстах ошибок. Браузер к провайдеру напрямую не обращается.
- Адрес собственного endpoint должен быть `https://`; `http://` допускается
  только для localhost и 127.0.0.1.

## Требования

- Node.js >= 20 (проверено на 26.x)
- npm (в комплекте с Node)

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:3000.

## Figma-плагин

Плагин **Illustration Composer** переносит ту же библиотеку и логику
компоновки в Figma. Код плагина — в `figma-plugin/`, движок подбора и раскладки
— общий с сайтом (`src/lib`).

### Установка

```bash
cd figma-plugin
npm install
npm run build
```

Сборка создаёт `figma-plugin/dist/code.js` и заново генерирует
`src/library.generated.ts` из `public/assets/illustrations`.

Затем в Figma Desktop:

1. Откройте меню Plugins → Development → Import plugin from manifest…
2. Выберите файл `figma-plugin/manifest.json`.
3. Запускайте плагин через Plugins → Development → Illustration Composer.

Перед публикацией замените значение `id` в `manifest.json` (сейчас заглушка
`REPLACE_WITH_FIGMA_PLUGIN_ID`) на id, выданный Figma для вашего плагина.
Импорт с заглушкой в этом репозитории не проверялся.

### Как работает

- **Вкладка «По описанию»** — вводите запрос на русском. Плагин подбирает
  объекты локальным алгоритмом (тот же, что на сайте). С включённым переключателем
  ИИ запрос отправляется модели Groq; при ошибке или некорректном ответе
  используется локальный подбор и показывается уведомление.
- **Вкладка «Компоненты»** — выбирайте объекты вручную до заданного количества;
  порядок слоёв задаёт раскладка.
- **Параметры** — цветовая схема, фон, размер L/S и формат холста.

Кнопки внизу:

- **Вставить в Figma** — создаёт новый фрейм `VectorMuse · …` с подложкой и
  объектами, размещённый по центру видимой области.
- **В выделенный фрейм** — добавляет объекты в выбранный FRAME без пересоздания;
  место подбирается так, чтобы минимально перекрывать существующие слои.
- **Экспорт SVG** — экспортирует выделенный фрейм и скачивает его из интерфейса.

### Ключ ИИ в плагине

- Ключ Groq вводится в интерфейсе плагина и хранится в `figma.clientStorage`
  без шифрования. В интерфейс возвращаются только последние 4 символа.
- Плагин обращается только к `https://api.groq.com` (разрешено в `manifest.json`).
  Другие провайдеры потребуют добавления их доменов в манифест.

## Структура

```
src/
  app/                 — маршруты Next.js (App Router) и корневой layout
  components/          — компоненты интерфейса (app, library, canvas, settings, compose, panel)
  lib/
    svg/               — разбор viewBox, проверка и очистка SVG-разметки
    palette/           — схемы, фоны, нормализация цветов, перекраска SVG
    metadata/          — валидация манифеста библиотеки и цветовых схем
    composition/       — форматы холста, авто-раскладка, геометрия, экспорт
    semantic/          — нормализация описания, словарь ассоциаций, ранжирование
    library/           — точка подключения библиотеки компонентов
  types/               — доменные типы (geometry, library, palette, composition)
figma-plugin/          — Figma-плагин (отдельная сборка, см. раздел выше)
tests/                 — модульные тесты (node:test, без внешних зависимостей)
docs/                  — ARCHITECTURE.md и FIGMA_SOURCE.md
public/assets/         — выгруженная из Figma библиотека SVG
```

Переменные окружения для запуска не требуются: ключи ИИ вводятся в интерфейсе.

## Архитектура и происхождение данных

- `docs/ARCHITECTURE.md` — модули, ответственность, поток данных.
- `docs/FIGMA_SOURCE.md` — структура исходного Figma-файла, размеры
  компонентов, цветовые схемы, план экспорта.
